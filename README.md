# ChunkCap-OG

Per-chunk cap for hangings (item frames, glow item frames, paintings, leash hitches) and vehicles (boats, chest boats, all minecart variants) on TrueOG Network.

Gradle Version: 8.14.3

Java Version: 17

Minecraft API: 1.19

API Jar: 1.19.4 Purpur
